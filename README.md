# A. Senno Odontologia

Site institucional one-page para clínica odontológica, em HTML, CSS e JavaScript puros.

**Tecnologias:** HTML5 · CSS3 · JavaScript · AOS (Animate On Scroll) · Font Awesome

**Destaques**

🦷 Seções de tratamentos, galeria de resultados e depoimentos com slider.

📱 Layout responsivo com menu mobile e header dinâmico ao rolar a página.

🔍 SEO técnico: meta tags Open Graph, dados estruturados (Schema.org) e robots/sitemap.

💬 Botão flutuante de WhatsApp para agendamento direto.

## Como usar

Basta abrir `index.html` no navegador ou publicar os arquivos estáticos em qualquer serviço de hospedagem (Netlify, Vercel, GitHub Pages).
